# AETHER OS

**FREEDOM. PERFORMANCE. CONTROL.**

AETHER OS é um projeto de sistema operacional desktop baseado em Linux, com foco prioritário em jogos, sem deixar de oferecer uma experiência completa para uso diário.

O objetivo é combinar desempenho, compatibilidade, privacidade, controle do usuário e uma interface familiar para quem vem do Windows.

> **Estado do projeto:** fase de planejamento e especificação. Este repositório contém documentação inicial; ainda não é uma distribuição instalável nem uma imagem ISO.

## Princípios

- **Desempenho:** priorizar uma experiência responsiva e uma pilha gráfica moderna.
- **Compatibilidade:** oferecer caminhos para executar jogos e aplicativos Windows quando tecnicamente possível.
- **Controle:** configurações amplas, pesquisáveis e compreensíveis.
- **Segurança:** alterações críticas devem ser validadas, reversíveis e explicadas.
- **Privacidade:** sem publicidade e sem telemetria invasiva.
- **Transparência:** documentar limitações, decisões e resultados de testes.

## Aviso

A compatibilidade com Windows não é universal. Jogos com determinados sistemas antitrapaça, DRM, drivers de kernel e aplicativos especializados podem não funcionar. Toda afirmação de compatibilidade deverá ser sustentada por testes e fontes verificáveis.
