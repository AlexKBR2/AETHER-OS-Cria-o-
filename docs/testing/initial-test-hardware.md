## Cuidados

- A RX 580 é uma GPU de geração anterior; validar suporte real de kernel, Mesa, Vulkan e recursos exigidos por cada jogo.
- Não presumir suporte a recursos gráficos recentes apenas porque Vulkan está disponível.
- Não alterar partições, discos, firmware ou instalação do Windows durante testes iniciais.
- Priorizar máquina virtual e mídia USB não persistente antes de qualquer teste em disco.
- Identificar corretamente cada unidade de armazenamento antes de qualquer operação que possa apagar dados.
