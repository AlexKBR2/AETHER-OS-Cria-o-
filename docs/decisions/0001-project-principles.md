# Decisão 0001 — Princípios do projeto

- **Estado:** aprovado como diretriz inicial
- **Data:** 2026-11-12

## Contexto

O AETHER OS deve combinar desempenho para jogos com uso cotidiano, ampla personalização e proteção contra configurações equivocadas.

## Diretrizes

1. Interface familiar e acessível.
2. Configurações extensas com explicações claras.
3. Recursos avançados sujeitos a validação e limites.
4. Mudanças críticas reversíveis sempre que possível.
5. Privacidade e transparência por padrão.
6. Desenvolvimento incremental, com testes isolados antes de tocar em instalações ou discos reais.

## Consequências

A seleção da base Linux, do modelo de atualização e das ferramentas de construção deverá considerar rollback, manutenção, segurança e facilidade de recuperação — não apenas desempenho bruto.
